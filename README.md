# Strimix — постановочная сцена для стрима

Статичный сайт из трёх страниц: лендинг вымышленного расширения → имитация авторизации → терминал «взлома».
Всё — чистая визуальная имитация: никаких сетевых запросов, полей ввода и данных посетителя.
IP-адреса берутся только из зарезервированных диапазонов (RFC 1918, CGNAT, TEST-NET), MAC — локально администрируемые.

| Страница | Что делает |
|---|---|
| `index.html` | Лендинг. Кнопки «Войти через Twitch» ведут на `auth.html` |
| `auth.html` | Спиннер и статусы ≈3 с → галочка «Авторизация успешна» → через ≈1 с переход на `terminal.html` |
| `terminal.html` | Сценарий «взлома» ≈20 с, терминал не стирается, последняя строка — `200 OK \| 146_art session_closed` |

## Управление терминалом (на экране никак не обозначено)

| Клавиша | Действие |
|---|---|
| `Space` | пауза / продолжение |
| `R` | перезапуск с начала |
| `F` | полноэкранный режим |
| `1`–`5` | мгновенный переход к фазе: 1 — подключение, 2 — токены, 3 — смена кошелька, 4 — выгрузка, 5 — финальная строка |

Клавиши работают в любой раскладке (используется `KeyboardEvent.code`). Курсор мыши на терминале скрыт.

## Запуск локально

Можно просто открыть `index.html` в браузере, но лучше через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Редактирование сценария

Весь сценарий — массив шагов в [`js/script-data.js`](js/script-data.js). В шапке файла описаны все типы шагов
(`cmd`, `out`, `progress`, `portscan`, `ls`, `download`, `hex`, `hashes`, `decrypt`, `banner`, `glitch`, `countdown`, `final` …)
и шаблоны вроде `{ip}`, `{mac}`, `{hash64}`, `{size:1-3M}`, `{$target}`. Метки `{ type: 'phase', id: N }` — это точки, куда прыгают клавиши 1–5.

Общий темп — `speed` в `TERMINAL_CONFIG` (1 — медленнее, 0.4 — быстрее). Тайминги страницы авторизации — в начале [`js/auth.js`](js/auth.js).

## Смена названия расширения

Название «Strimix» встречается только в текстах. Заменить везде (macOS):

```bash
grep -rl Strimix . --exclude-dir=.git | xargs sed -i '' 's/Strimix/НовоеИмя/g'
```

## Деплой на GitHub Pages

```bash
git init -b main
git add -A
git commit -m "Initial commit"
gh repo create strimix --public --source=. --push
gh api -X POST repos/{owner}/strimix/pages -f "source[branch]=main" -f "source[path]=/"
```

Через минуту-две сайт будет доступен по адресу `https://<ваш-логин>.github.io/strimix/`.
Статус сборки: `gh api repos/{owner}/strimix/pages/builds/latest`.

> Имя репозитория попадает в URL, который может увидеть чат, — поэтому оно нейтральное.

## Структура

```

css/terminal.css    — терминал, CRT, глитчи, баннеры

js/terminal.js      — движок терминала
js/script-data.js   — сценарий терминала
```
